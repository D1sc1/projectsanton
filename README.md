# Проекты курса C# (группы 24/3, 24/4)

Десять учебных проектов из папки `Projects.24.3.24.4` репозитория
[timkin-vn/CSharpCollege](https://github.com/timkin-vn/CSharpCollege/tree/master), выполненные как индивидуальный вариант.

За основу взят код преподавателя из ветки `master`. Структура решений, имена проектов и слои
(Business / Common / DataAccess / Wpf / Web) сохранены. Что менять, определено по веткам студентов:
изменения в `Projects.24.3.24.4` есть в 43 ветках. Типичные доработки:

| Проект | Веток с изменениями | Что обычно меняли студенты |
|---|---|---|
| 1. AlarmClock | ~21 | новые функции будильника: «отложить», повтор, мелодии, отображение времени |
| 2. Drawing | ~17 | свой рисунок в `PictureBuilder`, новые примитивы в `Painter` |
| 3. Calculator | ~20 | новые операции, дробные числа, обработка ошибок |
| 4. Calculator WPF | ~12 | те же операции в WPF/MVVM |
| 5. CardFile | ~11 | другая предметная область карточек (поля, файлы всех форматов, окно правки) |
| 6. GraphEditor | ~5 | новые фигуры, изменение размеров, цвета |
| 7–10. Game | ~9–10 | своя игра вместо «Пятнашек»: Сапёр, Морской бой, 2048, Lights Out и др. |

Для игр выбрана игра, которой нет ни в `master`, ни у других студентов: **Реверси (Отелло)**.

## Как запустить

Нужны Visual Studio 2022 и .NET Framework 4.7.2. При первой сборке восстановите NuGet-пакеты
(они, как и в `master`, не хранятся в репозитории).

Проекты 9 и 10 работают с PostgreSQL. Строки подключения — в `App.config`/`Web.config`
(`Main` — ADO.NET, `EFMain` — Entity Framework, пользователь `postgres`, пароль `Qwerty123`, как у преподавателя).
Подробно — в `9. Game DB/ReversiGame/ReversiGame.Wpf/Notes.txt` и
`10. Game Client-Server/ReversiGame/ReversiGame.Wpf/Notes.txt`.

* ADO.NET: создать пустую БД и выполнить `ReversiGame.DataAccess/Database/CreateTables.sql`.
* Entity Framework: БД создается автоматически при первом обращении.
* Клиент-сервер: сначала запустить `ReversiGame.Server.sln` (WebApi), затем `ReversiGame.Client.sln`.

## Проверка

* Весь C#-код 10 проектов компилируется под .NET Framework 4.7.2 с C# 7.3 (проверялось вне Visual Studio:
  для WPF проверены имена элементов и обработчиков событий из XAML, представления Razor просмотрены вручную).
* Логика будильника, калькулятора, картотеки (сохранение и чтение всех форматов файлов),
  графического редактора и правил Реверси проверена тестовыми прогонами; рисунок и редактор отрисованы в PNG.
* Тесты `9. Game DB/ReversiGame.UnitTests` (правила, сервисы на фейковых репозиториях, репозитории ADO.NET и EF)
  и серверные тесты проекта 10 проходят на PostgreSQL 16; клиентские тесты проекта 10 проходят против контроллеров
  Web API, запущенных в памяти (без IIS).
